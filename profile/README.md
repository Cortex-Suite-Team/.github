# Cortex Suite

**Cortex Suite builds controlled AI workers for real business operations.**

Chatbots answer. Workflow builders connect. Cortex operates.

Cortex Suite is a platform for designing, testing and running digital workers that execute business operations with structure, traceability and control. A Cortex worker can accept inputs, use tools, apply company knowledge, validate results, follow execution rules, leave traces and escalate risky cases when human judgment is required.

The platform is built for teams that need AI inside real operational workflows — not as a loose assistant, but as a controlled execution layer.

## What we build

Cortex Suite includes tools and components for:

- **Digital worker integration** — SDKs and widgets for connecting Cortex workers to external products and customer-facing interfaces.
- **Operational execution** — structured interaction with deployed workers through sessions, requests and runtime APIs.
- **Traceable AI automation** — controlled flows where inputs, outputs, usage, quality checks and escalations can be reviewed.
- **Platform extensibility** — public integration components for developers, integrators and product teams.

## Public repositories

This GitHub organization contains public packages and integration components for Cortex Suite.

Current public repositories include:

- [`cortex-sdk`](https://github.com/Cortex-Suite-Team/cortex-sdk) — SDK packages for working with Cortex Suite from external applications.
- [`cortex-sdk-ui`](https://github.com/Cortex-Suite-Team/cortex-sdk-ui) — UI components for Cortex Suite integrations.
- [`cortex-chat-widget`](https://github.com/Cortex-Suite-Team/cortex-chat-widget) — embeddable chat widget for connecting users to Cortex workers.

Core platform repositories are private.

## For developers

Use these repositories when you need to integrate Cortex Suite workers into your own application, product, portal or customer-facing interface.

Typical integration scenarios include:

- embedding a Cortex-powered worker into a web application;
- sending user requests to a deployed worker;
- receiving structured responses, messages or escalation states;
- connecting frontend interfaces to Cortex Suite runtime endpoints.

Public SDKs and widgets are intended to keep integration simple while preserving the operational controls handled by the Cortex Suite platform.

## For integrators

Cortex Suite is designed for teams that build AI-powered operational solutions for clients.

Instead of creating the whole AI workflow platform from scratch, integrators can use Cortex Suite as the execution layer and focus on business analysis, solution design, deployment and client success.
